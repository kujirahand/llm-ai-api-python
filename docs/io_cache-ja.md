# 入出力のキャッシュ

English: [io_cache.md](io_cache.md)

同じリクエストに対して API 呼び出しを省略し、前回の応答を SQLite から返す機能です。テストやデバッグで、課金と待ち時間を減らすために使います。応答は暗号化して保存します。

これは、ライブラリ側のローカルな応答キャッシュです。プロバイダー側のプロンプトキャッシュとは別のものです（[cache-ja.md](cache-ja.md)）。

## 有効にする

環境変数でディレクトリを指定します。

```sh
export LLM_AI_API_CACHE_DIR=./.llm_cache
```

コードで指定することもできます（環境変数より優先されます）。

```python
from llm_ai_api import llm

m = llm("openai:gpt-6-luna", cache_dir="./.llm_cache")
print(m.ask("可愛い犬の名前を考えて"))  # API を呼んで保存
print(m.ask("可愛い犬の名前を考えて"))  # キャッシュから返す（API を呼ばない）
```

指定がなければ、キャッシュは無効です。ディレクトリは、なければ作られます。保存先は `<ディレクトリ>/cache.db` の 1 ファイルです。

## 古いキャッシュを削除する

```python
from llm_ai_api import clear_cache

n = clear_cache(7)                         # 7 日より古いものを削除（環境変数のディレクトリ）
n = clear_cache(30, "./.llm_cache")        # ディレクトリを指定
n = clear_cache(0)                         # すべて削除
print(n, "件削除しました")
```

`days` 日より前に保存されたエントリを消し、消した件数を返します。ディレクトリがどこにも指定されていなければ `LLMConfigError`（`code="cache_dir_not_set"`）です。

## 仕様

- **キー**: `sha256("{プロバイダー}:{モデル}@{APIキー}>>>{入力}")` の16進文字列です。`{入力}` は、メソッド・パス・ストリームかどうか・リクエストボディ（`messages`、`temperature`、`max_tokens`、`extra` で足したものなど）を、キー順に並べた JSON にしたものです。
- **値**: 応答全体を暗号化して保存します。非ストリームは応答 JSON、ストリームは SSE イベントの一覧です。
- **API キーが違えば別のキャッシュ**になります。API キーはキーのハッシュの材料と、暗号鍵の導出にだけ使い、平文では保存しません。
- **暗号**: 標準ライブラリだけで実装しています（`scrypt` で API キーから鍵を導出し、HMAC-SHA256 のカウンターモードで暗号化し、HMAC で改ざんを検出します）。キャッシュを平文のまま置かないための保護で、API キーの管理に代わるものではありません。暗号鍵は API キーから作るので、API キーを持つ人は、キャッシュを読めます。
- 成功した応答だけを保存します。HTTP エラーは保存しません。
- ストリームは、最後まで読み切ったときだけ保存します。途中で止めたり、エラーになったりしたものは保存しません。
- 壊れたファイルや、改ざんされた値は、キャッシュなしとして扱い、API を呼びます。書き込みに失敗しても、呼び出しは失敗しません。
- 有効期限は自動では働きません。`temperature` を指定しなくても同じ応答が返り続けるので、新しい応答がほしいときは、`clear_cache()` を使うか、ファイルを消してください。
- キャッシュのファイルは、リポジトリにコミットしないでください。
