# 入出力のキャッシュ

English: [io_cache.md](io_cache.md)

同じリクエストに対して API 呼び出しを省略し、前回の応答を SQLite から返す機能です。テストやデバッグで、課金と待ち時間を減らすために使います。応答は暗号化して保存します。既定はオフです。

これは、ライブラリ側のローカルな応答キャッシュです。プロバイダー側のプロンプトキャッシュとは別のものです（[cache-ja.md](cache-ja.md)）。

## 有効にする

方法は 3 つあります。

```sh
# 1. 環境変数（<ディレクトリ>/cache.db を使う）
export LLM_AI_API_CACHE_DIR=./.llm_cache
```

```python
from llm_ai_api import llm, set_cache

# 2. プロセス全体（環境変数より優先。set_cache(None) で明示的にオフ）
set_cache("./cache.db")

# 3. インスタンスごと（グローバル設定より優先）
m = llm("openai:gpt-6-luna", cache="./cache.db")   # True なら既定の llm_ai_api_cache.db
off = llm("openai:gpt-6-luna", cache=False)         # このインスタンスだけオフ

print(m.ask("可愛い犬の名前を考えて"))  # API を呼んで保存
print(m.ask("可愛い犬の名前を考えて"))  # キャッシュから返す（API を呼ばない）
```

`SQLiteCache` オブジェクトを `cache=` や `set_cache()` に渡すこともできます。ディレクトリやファイルは、なければ作られます。

## 古いキャッシュを削除する

```python
from llm_ai_api import clear_cache

n = clear_cache(7)                    # 7 日より古いものを削除（環境変数のディレクトリ）
n = clear_cache(30, "./.llm_cache")   # ディレクトリを指定
n = clear_cache(0)                    # すべて削除
print(n, "件削除しました")
```

`days` 日より前に保存されたエントリを消し、消した件数を返します。ディレクトリは、引数、環境変数、`set_cache()` で設定したキャッシュの順に探します。どこにもなければ `LLMConfigError`（`code="cache_dir_not_set"`）です。`SQLiteCache.clear(days=None)` も同じ動きです。

## 仕様

- **対象**: `chat()` / `ask()` と、`stream_chat()` / `stream()`（ストリーミング）。生レイヤー（`request()`）は対象外です。
- **キー**: `sha256("{プロバイダー}:{モデル}@{APIキー}>>>{入力}")` の16進文字列です。`{入力}` は、リクエストボディ（`messages`、`temperature`、`max_tokens`、`extra` で足したもの、`stream` など）と、応答に影響するクライアント設定（`base_url`、追加ヘッダー、Anthropic の `anthropic_version`）を、キー順に並べた JSON にしたものです。
- **値**: 応答全体（`ChatResult`）を暗号化して保存します。ストリームは SSE イベントの一覧を保存し、キャッシュから返すときは同じイベントを再生します。
- **API キーが違えば別のキャッシュ**になります。API キーはキーのハッシュと暗号鍵の導出にだけ使い、平文では保存しません。
- **暗号**: 標準ライブラリだけで実装しています（`scrypt` で API キーから鍵を導出し、HMAC-SHA256 のカウンターモードで暗号化し、HMAC で改ざんを検出します。HMAC にはキャッシュのキーも含めるので、暗号文を別の行へ移し替えても検出されます。API キーを使う読み込みでは、暗号化されていない値は受け付けません）。キャッシュを平文のまま置かないための保護で、API キーの管理に代わるものではありません。暗号鍵は API キーから作るので、API キーを持つ人は、キャッシュを読めます。
- 成功した応答だけを保存します。HTTP エラーは保存しません。
- ストリームは、終端イベント（`[DONE]` や `message_stop`）まで読み切ったときだけ保存します。終端イベントなしで途切れたもの、途中で止めたもの、エラーになったものは保存しません。
- 壊れた行や、改ざんされた値は、キャッシュなしとして扱い（その行は削除します）、API を呼びます。実行時にキャッシュの読み書きに失敗しても、呼び出しは失敗しません。
- ファイルを新規作成するときの権限は、所有者のみ（0600）です。
- 有効期限は自動では働きません。同じリクエストには同じ応答が返り続けるので、新しい応答がほしいときは、`clear_cache()` を使うか、オフにしてください。
- キャッシュのファイルは、リポジトリにコミットしないでください。
